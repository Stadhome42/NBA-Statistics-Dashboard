# 🏀 NBA Advanced & Basic Analytics Dashboard

An interactive sports analytics dashboard and automated data pipeline built for a university Final Year Project. This application extracts over a decade of historical NBA team-level data (traditional box scores and advanced efficiency metrics) via `nba_api`, engineers rolling moving averages, and presents actionable insights through a responsive local Streamlit web interface.

---

## 🛠️ Tech Stack & Dependencies

*   **Python** (3.10+)
*   **Streamlit** (Web framework for the interactive dashboard)
*   **Plotly Express** (Dynamic, responsive data visualizations)
*   **Pandas** (Data processing, aggregation, and merging)
*   **nba_api** (API client wrapper for official NBA.com data endpoints)
